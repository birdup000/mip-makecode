MiP Connect

  1. In this folder run python3 -m http.server, then open the page in Chrome or Edge.
  2. Drag MiP Connect to the bookmarks bar.
  3. In MakeCode Arcade, import this extension and start a game.
  4. Click the bookmark. A MiP card appears. Choose Connect and pick the robot named Mip-…
  5. Use the MiP blocks. The line at the bottom of the simulator shows the link.

Chrome and Edge on a computer or Android can open the Bluetooth chooser. Safari cannot.
